A LUNA agora possui memória persistente local.

Ela grava conversas e fatos explicitamente ensinados pelo usuário em `%LOCALAPPDATA%/LunaIA/memory/long-term-memory.json`.

Exemplos que a memória reconhece:
- Meu nome é ...
- Prefiro que você ...
- Meu projeto é ...
- Meu computador é ...
- Meu navegador é ...
- Não quero que você ...

A memória estruturada é independente do Qwen e poderá alimentar respostas e decisões futuras.
