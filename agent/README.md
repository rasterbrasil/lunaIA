# LUNA PC Agent

Este diretório será o agente residente do Windows.

A primeira implementação será incremental. Antes de adicionar controle do sistema operacional, o agente deve ter:

1. configuração local segura;
2. ciclo de vida (iniciar/parar);
3. logging estruturado;
4. camada de áudio desacoplada;
5. adaptador de IA desacoplado;
6. registro de ferramentas e permissões.

Não coloque tokens ou credenciais neste diretório.
